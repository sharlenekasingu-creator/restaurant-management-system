# Restaurant Management System — Prompt-by-Prompt Python Development Plan

## How to use these prompts

Use them **sequentially**.

```text
Prompt 1 → Generate code
       ↓
Run/test the code
       ↓
Prompt 2 → Generate next code
       ↓
Run/test the code
       ↓
Prompt 3 → Generate next code
       ↓
...
       ↓
Final Prompt → Complete tested RMS
```

Each prompt assumes that the code generated by the previous prompt has been retained.

The AI should **modify existing files where appropriate rather than recreating the project from scratch**.

Do not replace existing working functionality unnecessarily.
